# Clínica Uroclinic - Sistema de Gestión

## Tecnologías
- Frontend: React + Vite
- Backend: Node.js + Express
- Base de datos: MySQL

## Instalación

### Backend
  ash
cd backend
npm install
npm run dev
  

### Frontend
  ash
cd frontend
npm install
npm run dev
  

## Estructura del proyecto
- /frontend - Aplicación React
- /backend - API Node.js
- /database - Scripts SQL
